# Vedanshi Enterprises — Website

Transport • Real Estate • Telecom • Packaging • Scrape

Static, dependency-free multi-page site (8 pages): Home, About, Contact, and one page per service.

- Edit content in `build.py`, then run `python3 build.py` to regenerate the HTML pages.
- Styles: `assets/css/style.css` · Scripts: `assets/js/main.js`
- Preview locally: `python3 -m http.server 8000`
